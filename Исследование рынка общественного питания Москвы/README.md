## О проекте
Этот аналитический проект посвящен исследованию рынка заведений общественного питания в Москве. Исследование было проведено по запросу инвесторов из фонда "Shut Up and Take My Money", которые планируют открыть кофейню в стиле знаменитого "Central Perk" из сериала "Друзья".

**Цель исследования**

Основная цель проекта — проанализировать текущее состояние рынка общественного питания Москвы, выявить ключевые тенденции и особенности, которые помогут инвесторам принять обоснованное решение о формате и расположении нового заведения.

**Ключевые аспекты анализа**
- Категории заведений: распределение по типам (кафе, рестораны, кофейни и др.)
- Географическое распределение: анализ по административным округам Москвы
- Сетевые и независимые заведения: доля и характеристики
- Ценовая политика: средний чек по категориям и районам
- Рейтинги заведений: сравнение по категориям и округам
- Особенности кофеен: отдельный углубленный анализ

**Методология**

Проект выполнен в Jupyter Notebook с использованием Python и следующих библиотек:

- Pandas и NumPy для обработки данных
- Matplotlib и Seaborn для визуализации
- Folium и Plotly для создания интерактивных карт

**Результаты**

Исследование выявило ключевые инсайты о московском рынке общепита, включая:

- Распределение заведений по категориям и районам
- Средние чеки и рейтинги в разных сегментах
- Особенности расположения и работы кофеен
- Конкурентную среду и потенциальные ниши

**Практическая ценность**

Результаты исследования помогут инвесторам:

- Определить оптимальный формат заведения
- Выбрать перспективное местоположение
- Сформировать конкурентное ценовое предложение
- Разработать уникальную концепцию, учитывающую рыночные тренды

Проект демонстрирует возможности data-driven подхода к принятию бизнес-решений в сфере общественного питания.
