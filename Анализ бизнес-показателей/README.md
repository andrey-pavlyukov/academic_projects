## Описание проекта

Приложение Procrastinate Pro+ вкладывает огромные средства в рекламу, но последние несколько месяцев компания терпит убытки. В рамках этого аналитического исследования я проведу глубокий анализ бизнес-показателей, чтобы выявить причины убытков и помочь компании выйти в плюс.

**Почему этот проект важен?**

- Большие рекламные бюджеты требуют четкого понимания их эффективности
- Убытки компании сигнализируют о проблемах в монетизации или привлечении пользователей
- Комплексный подход к анализу поможет выявить скрытые проблемы и возможности для роста

**Что я исследую?**

В моем распоряжении уникальные данные о пользователях за период с 1 мая по 27 октября 2019 года:
- Лог сервера с данными о посещениях
- Выгрузка покупок пользователей
- Данные о рекламных расходах

**Ключевые вопросы исследования:**
- Откуда приходят пользователи и какими устройствами они пользуются?
- Сколько стоит привлечение пользователей из различных рекламных каналов?
- Сколько денег приносит каждый клиент?
- Когда расходы на привлечение клиента окупаются?
- Какие факторы мешают привлечению клиентов?

**Методология анализа:**
- Предобработка данных для обеспечения качества анализа
- Исследовательский анализ пользовательских профилей, географии, устройств и каналов привлечения
- Расчет ключевых метрик: LTV, ROI, удержание и конверсия
- Оценка окупаемости рекламы с разбивкой по устройствам, странам и каналам продвижения
- Анализ динамики изменений конверсии и удержания пользователей

**Ожидаемые результаты:**
- Выявление неэффективных каналов привлечения
- Определение оптимальных стратегий монетизации
- Рекомендации по оптимизации рекламных бюджетов
- Понимание профиля наиболее ценных пользователей
- Выявление проблемных точек в пользовательском опыте

Мой проект — не просто анализ данных, а возможность найти реальные решения для вывода компании на прибыльность. Каждый график и расчет приближает нас к пониманию, как сделать Procrastinate Pro+ успешным продуктом.
