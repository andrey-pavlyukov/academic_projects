## Обзор проекта
Этот исследовательский проект посвящен анализу данных о продажах видеоигр с целью выявления закономерностей, определяющих их успешность. Исследование основано на данных интернет-магазина "Стримчик" и включает информацию о платформах, жанрах, продажах в разных регионах, оценках критиков и пользователей, а также возрастных рейтингах игр.

### Основные этапы исследования
**Предобработка данных:** Приведение данных к единому формату, обработка пропусков и аномалий, добавление новых признаков (общемировые продажи и типы платформ).

**Исследовательский анализ:**
- Динамика выпуска игр по годам
- Анализ продаж по платформам
- Определение актуального периода для прогнозирования
- Влияние отзывов на продажи
- Распределение игр по жанрам
- ТОП-5 популярных платформ и жанров в разных регионах (Северная Америка, Европа, Япония)
- Влияние возрастного рейтинга ESRB на продажи

**Проверка гипотез:**
- Сравнение пользовательских рейтингов платформ Xbox One и PC
- Сравнение пользовательских рейтингов жанров Action и Sports

### Проект реализован на Python с использованием библиотек
- Pandas для работы с данными
- NumPy для математических операций
- Matplotlib и Seaborn для визуализации
- Scipy для статистического анализа

### Результаты исследования помогут
- Определить потенциально популярные продукты
- Оптимизировать рекламные кампании
- Понимать предпочтения пользователей в разных регионах
- Принимать обоснованные решения о закупках и продвижении игр
