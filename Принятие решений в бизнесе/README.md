## Описание проекта
Этот аналитический проект посвящен оптимизации бизнес-процессов интернет-магазина через приоритизацию гипотез и анализ результатов A/B-тестов. Проект выполнен в формате Jupyter Notebook и включает два основных раздела:

**Приоритизация гипотез:**

- Применение фреймворков ICE и RICE для оценки 9 маркетинговых гипотез
- Сравнение результатов двух методов приоритизации
- Выявление наиболее перспективных идей для увеличения выручки

**Анализ A/B-теста:**

- Комплексная оценка результатов A/B-теста по 14 ключевым метрикам
- Визуализация кумулятивных показателей (выручка, средний чек, конверсия)
- Статистический анализ различий между группами
- Выявление аномальных пользователей и заказов
- Принятие решения по результатам теста

**Особенности проекта**

- Использование Python и популярных библиотек (pandas, numpy, matplotlib, seaborn, scipy)
- Тщательная предобработка данных (проверка на дубликаты, аномалии, приведение типов)
- Разработка вспомогательных функций для автоматизации анализа
- Применение статистических тестов (Шапиро-Уилк, Манна-Уитни)
- Визуализация результатов (matplotlib, seaborn)

**Выводы и рекомендации для бизнеса**

Проект демонстрирует полный цикл аналитической работы: от приоритизации гипотез до анализа результатов экспериментов, что делает его ценным примером для специалистов в области data-driven маркетинга и e-commerce аналитики.
