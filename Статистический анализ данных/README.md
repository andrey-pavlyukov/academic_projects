## Описание проекта
Этот проект представляет собой комплексный статистический анализ данных сервиса аренды самокатов GoFast. В исследовании используются данные о пользователях из нескольких городов и их поездках для проверки ключевых гипотез, которые помогут сервису в развитии бизнеса.

### Основные направления анализа:
**Исследовательский анализ данных:**

- Частота встречаемости городов
- Соотношение пользователей с подпиской и без подписки
- Возрастная структура пользователей
- Анализ расстояний и продолжительности поездок
- Расчет средней скорости поездок

**Финансовые показатели:**

- Подсчет выручки сервиса
- Сравнение доходности от разных типов подписок

**Проверка гипотез:**

- Влияние типа подписки на продолжительность поездок
- Сравнение расстояний поездок с рекомендуемыми значениями
- Анализ выручки от разных категорий пользователей
- Оценка влияния обновления серверов на количество обращений в техподдержку

**Маркетинговые исследования:**

- Расчет необходимого количества промокодов для акции
- Оценка вероятности открытия push-уведомлений

### Особенности проекта:
- Использование современных библиотек Python (Pandas, NumPy, SciPy, Matplotlib, Seaborn) для анализа и визуализации данных
- Разработка специализированных функций для автоматизации исследования
- Предобработка данных (обработка пропусков, дубликатов, аномалий)
- Подробное исследование распределений ключевых показателей
- Проверка статистических гипотез с расчетом p-значений
- Cтруктура с навигацией по разделам анализа

Проект представляет собой полноценное исследование, результаты которого могут быть использованы для оптимизации бизнес-процессов сервиса GoFast, улучшения пользовательского опыта и повышения прибыльности компании.

### Технологический стек:
- Python
- Pandas
- NumPy
- SciPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Проект выполнен в формате Jupyter Notebook с подробными комментариями и выводами на каждом этапе анализа.
