## Обзор проекта

Этот исследовательский проект посвящен комплексному анализу поведения пользователей мобильного приложения с акцентом на изучение воронки продаж и проведение A/A/B-тестирования новых шрифтов. Проект выполнен в формате Jupyter Notebook и включает все этапы работы с данными: от предварительной обработки до глубокого анализа и визуализации результатов.

**Ключевые аспекты исследования**
1. Подготовка и предобработка данных
  - Приведение названий столбцов к единому стилю
  - Обработка пропущенных значений и дубликатов
  - Добавление временных меток и преобразование данных
  - Создание набора вспомогательных функций для автоматизации анализа

2. Исследование пользовательского поведения
  - Анализ общего количества событий и уникальных пользователей
  - Изучение среднего количества событий на пользователя
  - Определение временного периода данных и их полноты
  - Визуализация динамики событий по группам

3. Анализ воронки событий
  - Идентификация ключевых событий в логах
  - Расчет конверсии между этапами воронки
  - Определение точек наибольшей потери пользователей
  - Оценка доли пользователей, доходящих до оплаты

4. Проведение A/A/B-теста
  - Сравнение контрольных групп между собой
  - Проверка корректности разбиения на группы
  - Анализ статистической значимости различий
  - Оценка влияния нового шрифта на поведение пользователей
  - Учет поправки Бонферрони для множественного тестирования

**Технический стек**
- Python (Pandas, NumPy, SciPy)
- Библиотеки визуализации (Matplotlib, Seaborn, Plotly)
- Статистические методы анализа данных
- Принципы A/B-тестирования
